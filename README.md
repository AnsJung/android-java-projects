# Android Java Projects

Java로 만든 Android 프로젝트를 모아둔 저장소입니다. 각 프로젝트는 자체 Gradle 설정을 갖고 있습니다.

| 프로젝트 | 설명 | 원본 저장소 |
| --- | --- | --- |
| [NewWord-Dic](./NewWord-Dic/) | 신조어를 검색하고 게시판을 이용할 수 있는 사전 앱 | [원본](https://github.com/AnsJung/NewWord-Dic) |
| [RequestSearch](./RequestSearch/) | 네이버 검색 API를 사용한 책·영화 검색과 오타 변환 예제 | [원본](https://github.com/AnsJung/RequestSearch) |
| [IdeaMarket](./IdeaMarket/) | 아이디어 거래와 협업을 위한 앱 프로젝트 (미완성) | [원본](https://github.com/AnsJung/IdeaMarket) |

Android Studio에서 `File > Open`을 선택한 뒤, 열고 싶은 프로젝트 폴더를 선택하세요.
